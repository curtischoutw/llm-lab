# 02: 匯入圖片

**What to build:** 使用者可以用 `ingest` 匯入單張圖片（.png .jpg .jpeg .bmp .tiff .tif .gif .webp），匯入後問得到圖片的內容；匯入資料夾時，PDF 和圖片都會被挑出來，不支援的檔案列出檔名後略過。Python API 同樣接受圖片。這條路徑不需要 LibreOffice，是第一條端到端打通的新格式。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 支援的格式在專案裡只定義一次，這張先放 PDF 與 8 種圖片格式，副檔名大小寫不分；CLI 的過濾、錯誤訊息、文件都從這份清單取值。
- [ ] CLI 匯入單張圖片成功，匯入後用 `query` 問得到假 mineru 輸出的內容。需要轉成 png 的格式（至少一種，例如 .webp 或 .bmp）也能匯入。
- [ ] 匯入資料夾時，不遞迴，依檔名排序挑出 PDF 與圖片；不支援的檔案逐一印出「略過不支援的格式：<檔名>」，不算錯誤。
- [ ] 單一檔案格式不支援時，以非零碼結束，訊息列出支援的格式。資料夾裡沒有任何支援的文件時，以非零碼結束。
- [ ] 重複匯入同一張圖片時略過，不呼叫模型；中斷後重新匯入會重試，不留下重複紀錄。行為和 PDF 相同。
- [ ] Python API 縫：`Session.ingest` 與模組函式 `ingest` 接受圖片，報告欄位是 `document`。
- [ ] 先紅後綠：每個新行為先寫出失敗的測試並貼出失敗輸出，再實作。「單一非 PDF 檔被拒絕」的既有測試，改寫成「支援的格式接受、不支援的拒絕」，並在本 ticket 的實作結果寫明理由（需求改變）。
