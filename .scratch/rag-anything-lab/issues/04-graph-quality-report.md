# 04: 圖譜品質檢視

**What to build:** `ingest` 完成後能看到知識圖譜的實體數與關係數，並抽樣列出實體，讓使用者判斷 4B 的 LLM 抽取品質夠不夠用。本張只交出數據與觀察；是否升級 LLM 由使用者決定。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] `ingest` 結束時印出實體數與關係數。
- [ ] 能抽樣列出 10 個實體（含名稱與類型或描述），並列出涉及這些實體的關係。
- [ ] 針對第一篇已匯入的論文，回報：實體數、關係數、10 個抽樣實體，以及觀察到的問題類型（格式錯誤造成的漏抽、重複實體、無意義實體等），各附實例。
- [ ] 回報結尾列出升級選項（LightRAG 官方建議的本地下限為 Qwen3-30B-A3B-Instruct），但不自行更換 LLM 設定；等使用者決定。
- [ ] 結論只寫實際看到的內容，不給「品質良好」之類沒有依據的評語。
