# 02: 官網金融卡的條款與說明頁

**What to build:** 下載腳本也會下載官網金融卡的約定條款、費用與常見問題，以及存款專區的晶片金融卡說明，讓「金融卡跨行提款手續費多少」「晶片金融卡有沒有回饋」這類問題有資料可答。分成兩個類別（spec「下載腳本」的類別表）：「金融卡約定條款 PDF」從約定條款頁收集同網域的 PDF 連結，照原檔存到 `debit_terms/`；「金融卡說明頁」是寫死的 7 個網址（費用、常見問題 2 頁、Richart 摘要頁、存款專區晶片金融卡 3 頁），照 01 的方式轉檔存到 `debit_info/`。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 約定條款 PDF 存到 `debit_terms/`，名稱 `debit_term_<PDF 主檔名>`；約定條款頁上指向悠遊卡公司（外部網域）的連結略過。約定條款頁本身不存成文件。
- [ ] 說明頁 7 個網址取 `#centercontainer` 後轉成文件，存到 `debit_info/`，名稱 `debit_info_<網址最後一段>`；沒有主內容區或請求失敗時記失敗，其他照常。
- [ ] 名稱不和現有文件撞名；下載清單照現有欄位記錄。
- [ ] 更新模式：PDF 內容沒變不重寫、說明頁主內容區變了才重新轉檔；約定條款頁上消失的 PDF 搬到 `_meta/removed/<日期>/`，約定條款頁失敗或解析出 0 份而本地有檔案時不判斷；說明頁沒有下架判斷，取不到時本地檔案不動。
