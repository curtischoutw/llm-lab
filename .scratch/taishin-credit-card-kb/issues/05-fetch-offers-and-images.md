# 05: 下載刷卡優惠活動與主視覺圖片

**What to build:** 下載腳本也會翻完刷卡優惠的每個分類與分頁，把下載當天還沒結束的活動頁列印成 PDF，放進活動資料夾。前 8 個有主視覺的活動，另外把主視覺存成圖片文件。已過期與期間不明的活動都記在下載清單裡。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 在 `mkpcard` 的刷卡優惠列表翻完分類 A–I 的每一頁，直到沒有新連結為止，取出 `mkp` 上的活動詳情頁連結並去除重複。這兩個網域的網址前綴都可以用環境變數替換。
- [ ] 從活動詳情頁讀出活動期間。結束日早於下載當天就略過，記為過期；讀不出期間時照樣下載，記為期間不明。清單記錄活動期間。
- [ ] 活動頁用 headless Chrome 列印成 PDF，原始 HTML 照 02 的方式保存。
- [ ] 依發現順序，取前 8 個有主視覺的活動頁，把主視覺存成圖片文件；只收支援的圖片格式，其他略過並記入清單。主視覺的判斷方式依實際 HTML 確認後寫進 docstring（spec 的 ASSUMPTION：內容區的第一張圖片）。
- [ ] 單頁失敗時其他頁照常完成；列表頁失敗時以非零碼結束並指出是哪一個列表。
- [ ] 以子行程測試分類與翻頁、過期與期間不明、圖片數量上限與不支援格式的略過。
- [ ] 下載腳本的測試、主測試套件與既有下載腳本的測試都全綠。
