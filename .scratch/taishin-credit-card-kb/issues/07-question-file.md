# 07: 寫題目檔

**What to build:** 一份 20 題的題目檔，參考答案依下載當天的原文撰寫，涵蓋切換、權益、回饋規則、費用、約定條款、優惠活動與跨卡比較，讓使用者能判斷知識庫答得對不對。

**Blocked by:** 06（參考答案要依實際下載的原文撰寫）

**Status:** ready-for-agent

- [ ] 新增題目檔並納入版本控管，欄位沿用現有格式：`id`、`question`、`reference`、`type`、`source`。
- [ ] 類別寫在 `id` 前綴，題數至少為：`switch-` 4、`benefit-` 2、`rule-` 2、`fee-` 2、`terms-` 2、`offer-` 2、`cross-` 2，合計 20。
- [ ] 切換的 4 題涵蓋：有哪些回饋方案、什麼時候能切換與限制、切換後當天消費怎麼算、哪些舊卡適用。
- [ ] `type` 沿用現有的四個值，跨卡比較題用 `cross-paper`。`source` 填本地檔名，多份時用逗號分隔。
- [ ] 參考答案依原文撰寫；原文有錯字或前後不一致時，照原文寫並加註。
- [ ] 題目檔通過 `eval` 的格式驗證（用不需要模型的方式確認，例如讀檔驗證的測試路徑，或模型 server 關閉時的錯誤訊息確認不是格式錯誤）。
- [ ] 文字符合使用者的寫作規則。
