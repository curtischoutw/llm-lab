# 06: 實機下載與試匯入

**What to build:** 對真的官網跑一次下載，確認四類內容都下載到了。接著試匯入 7 份有代表性的文件，量測耗時與記憶體，並確認中文被正確抽出，作為全量匯入前的依據。

**Blocked by:** 01、05

**Status:** ready-for-agent

- [ ] 實際執行下載腳本。核對各類數量（卡片約 16、權益子頁約 45、下載區 PDF 約 19、活動數依當天而定、圖片最多 8），檢查下載清單裡的過期、期間不明、失敗筆數；有失敗時記下原因並回報。
- [ ] 抽查轉出的 PDF 與 `.docx`，看內容是否完整（和原始 HTML 比對幾頁的文字）。
- [ ] 照 README 啟動兩個 MLX server，以 zsh 執行 watchdog（門檻 22 GB），smoke test 三項 PASS。
- [ ] 試匯入 7 份文件：Richart 卡片頁、約定條款 PDF、2 個權益子頁、2 個活動頁、1 張活動圖片。用 symlink 放進試匯入資料夾後匯入。
- [ ] 記錄每份文件的耗時、Office 轉檔時間（從 log 讀出）、wired 記憶體峰值，並依這些數字估計全量匯入的總時間。
- [ ] 抽查 MinerU 的內容清單，確認中文沒有變成亂碼；有問題時記下事實並回報，不改設定。
- [ ] README：新增下載腳本的用法（含更新權益時要刪除後重新下載、重新匯入），以及試匯入的量測數字。
- [ ] 輸出與 log 存在 `output/` 底下新的資料夾；驗證完關閉 server 與 watchdog。
- [ ] 文字符合使用者的寫作規則。
