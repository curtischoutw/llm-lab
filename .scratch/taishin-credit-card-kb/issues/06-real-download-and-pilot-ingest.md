### 試匯入
- 第一次試匯入：總計 2:01:01，7 份全部 processed。log 在 `output/taishin_pilot/ingest.log`。
  - 問題：2 份權益 docx 的 MinerU 內容清單中文是 0 字。
  - 根因：headless LibreOffice 透過 fontconfig 找字型，看不到 macOS 系統字型，中文字沒有畫進 PDF。
    - 純文字檔與極簡 HTML 經 LibreOffice 輸出 PDF，中文也是 0 字。
    - 只安裝 Noto Sans CJK TC 字型，仍然是 0 字。
    - 用 `FONTCONFIG_FILE` 指向一份列出系統字型資料夾的 fontconfig 設定後，有 7,265 字。
  - 使用者的決定（2026-10-30）：
    - 新增 `scripts/libreoffice-fonts-macos.conf`，在 `.env.example` 與 README 第 1 節說明。使用者自己在 `.env` 加上 `FONTCONFIG_FILE`。
    - 移除 Noto 字型。
    - 刪除 `rag_storage/` 與 2 份 docx 的解析輸出，全量重新匯入。
