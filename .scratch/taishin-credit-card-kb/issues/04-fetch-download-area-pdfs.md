# 04: 下載文件下載區的 PDF

**What to build:** 下載腳本也會翻完信用卡文件下載區的每一頁，把所有 PDF 原樣放進下載資料夾。約定條款、保險證、費用表、機場接送規則、申請書與授權書都會進入知識庫。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 從文件下載頁的第 1 頁開始往後翻，直到某一頁沒有新的 PDF 連結為止；PDF 網址去除重複。
- [ ] PDF 不轉檔，原樣存檔。本地檔名整批唯一，下載清單記錄每一份（沒有原始 HTML 的 SHA-256 欄位值）。
- [ ] 某一份 PDF 下載失敗時，其他照常完成，最後以非零碼結束；下載頁本身失敗時，以非零碼結束並指出是哪一個列表。
- [ ] 以子行程測試翻頁、去除重複與失敗處理。
- [ ] 下載腳本的測試、主測試套件與既有下載腳本的測試都全綠。
