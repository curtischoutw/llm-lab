# 08: 更新模式：官網列表裡沒有的，搬到 `_meta/removed/<日期>/`

**What to build:** 更新模式下，卡片、權益子頁、下載區、活動四個列表類別，這次列表裡沒有、本地有的文件，搬到該類別資料夾的 `_meta/removed/<日期>/`，清單記「下架」；之後 `ingest` 就看得到它不在了。某個類別的列表頁沒有成功取得時，那個類別這次不搬任何檔案，報告寫明原因（spec「下載腳本：更新模式」的下架判斷）。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 列表少了一份：文件連同它在 `_meta` 底下的原始 HTML 與列印暫存，搬到 `_meta/removed/<日期>/`，清單記「下架」。
- [ ] 目的地已有同名檔時，在檔名後加時間，不覆寫（ASSUMPTION，見 spec）。
- [ ] 列表頁請求失敗或逾時：那個類別不搬任何檔案，報告寫明類別與原因；其他類別照常。
- [ ] 不設下架數量的比例門檻。
- [ ] `_meta` 底下的檔案不會被 `ingest` 挑出（確認現有行為）。
- [ ] 測試沿用假 HTTP server；現有測試全綠。
