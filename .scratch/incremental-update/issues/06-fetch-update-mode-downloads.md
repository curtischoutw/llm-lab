# 06: 下載腳本的更新模式骨架：下載區 PDF 只換內容真的變了的

**What to build:** 使用者用更新模式執行下載腳本時，下載區的 PDF 會重新下載到暫存位置並比對 `sha256`：內容不同才換掉原檔，相同就不碰原檔（修改時間不變，下次匯入走解析快取）。下載清單與結束時的統計多了「內容變更」「未變」兩種結果。不開更新模式時，行為與現在完全相同（spec「下載腳本：更新模式」）。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 開工第一步，實測並把結果與指令寫進這張 ticket 的 Comments（對官網的請求遵守現有的請求間隔，卡片頁、權益子頁、活動頁各最多 1 頁）：(a) 同一個網頁抓兩次，原始 HTML 是否相同；(b) 同一份 HTML 以 Chrome headless 列印兩次、以 LibreOffice 轉兩次，位元組是否相同。(a) 顯示原始 HTML 每次都不同時，停下來回報，比對規則由使用者決定。
- [ ] 新增開啟更新模式的命令列選項；不開時既有測試全綠。
- [ ] 下載區 PDF 內容沒變：原檔的位元組與修改時間不變，清單記「未變」。
- [ ] 內容變了：原檔換成新內容，清單記「內容變更」。
- [ ] 下載失敗：原檔不動，清單記失敗。
- [ ] 結束時印出各類別、各結果的數量。
- [ ] 測試沿用下載腳本子行程＋假 HTTP server 的縫。
- [ ] README 第 2 節寫明更新模式的用法與目前涵蓋的類別。
