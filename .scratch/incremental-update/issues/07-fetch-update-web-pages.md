# 07: 更新模式：網頁類用原始 HTML 判斷有沒有變

**What to build:** 更新模式下，卡片頁、權益子頁、活動頁重新取得原始 HTML，與類別資料夾 `_meta/html/` 裡存的上一份原始 HTML 比對（不用下載清單當基準：清單每次整份重寫，只含這次處理到的文件）：變了才重新轉檔並換掉文件，清單記「內容變更」；沒變就不轉檔、不碰文件（spec「下載腳本：更新模式」的變更判斷）。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] HTML 沒變：不呼叫 Chrome／LibreOffice，文件的位元組與修改時間不變，清單記「未變」。
- [ ] HTML 變了：重新轉檔，換掉文件與存檔的原始 HTML，清單記「內容變更」並更新雜湊。
- [ ] 轉檔成功後才換掉存檔的原始 HTML 與文件；轉檔失敗時兩者都不動，清單記失敗，下次執行會再比對到差異並重試。
- [ ] 測試沿用假 HTTP server、假 Chrome、假 LibreOffice；現有測試全綠。
