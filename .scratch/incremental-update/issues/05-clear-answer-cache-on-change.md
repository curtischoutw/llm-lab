# 05: 知識庫有改動時清掉答案快取

**What to build:** 一次 ingest 只要有新增、替換或刪除成功，結束前清掉 LLM 快取裡所有查詢答案的項目，保留關鍵字快取與匯入用的抽取快取；之後同一題會用新的知識庫重新回答。全部沒變時不清。報告寫出清掉的筆數（spec「匯入端：答案快取」）。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 有新增（或替換、刪除）時：先前問過的題目再問一次，會重新呼叫假 LLM 生成答案（從假 server 的請求紀錄觀察）。
- [ ] 關鍵字快取保留：同一題再問時，不重新呼叫抽關鍵字。
- [ ] 全部沒變，或只有失敗（失敗時寫入一半的內容已刪）時：同一題再問仍命中答案快取。
- [ ] 先前失敗的文件這次重試成功：算新增，清答案快取。
- [ ] 報告寫出清掉的答案快取筆數；CLI 與 Python API 行為相同。
- [ ] README 寫明這個行為；現有測試全綠。
